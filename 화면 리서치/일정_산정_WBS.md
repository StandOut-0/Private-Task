# 나우앤서베이 리뉴얼 일정 산정 (WBS)

## 개요
와이어프레임 기반 나우앤서베이 UI/UX 리뉴얼 프로젝트 일정 산정입니다. 인원별(2명/3명/4명) 워크데이 기준으로 상세 일정을 제시합니다.

## 프로젝트 개요
- **총 기간**: 8~12주 (약 2~3개월)
- **작업 범위**: 화면 리서치 분석 기반 전면 리뉴얼
- **주요 작업**: 디자인 시스템 구축, 프론트엔드 개발, 백엔드 개발, 테스트

## 인원 구성
- **프론트엔드 개발자**: UI/UX 구현, 상태 관리, API 연동
- **백엔드 개발자**: API 설계, 데이터베이스 구조, 서버 개발
- **디자이너**: 디자인 시스템, UI/UX 디자인 (3명 이상)
- **PM/기획**: 프로젝트 관리, 요구사항 분석 (4명 이상)
